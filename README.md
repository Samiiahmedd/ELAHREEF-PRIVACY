# ELHAREF Privacy Policy

## Publish with GitHub Pages

1. Create a GitHub repository, for example: `elharef-privacy-policy`
2. Upload `index.html`.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide a public URL similar to:
   https://YOUR_USERNAME.github.io/elharef-privacy-policy/

## Important
Before publishing, open `index.html` and replace:

YOUR_SUPPORT_EMAIL

with the official ELHAREF support email address.

Then use the resulting public URL in:
App Store Connect → App Information → Privacy Policy URL
